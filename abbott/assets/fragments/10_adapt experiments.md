# Adapt lesson experiments

<p class="note">Six different spatial ideas, not six colourways: an editorial spread with a side brief, a technical maker bench, cinematic story scenes, a case-file evidence board, an expedition route and an open creative studio. Each stage changes composition as the lesson progresses. Abstract graphics stand in for media widgets; evidence sources can be opened, and journal fields accept practice notes.</p>

<p class="note">Six alternative compositions using the same page → article → block → component hierarchy. The collapsible workbench H3 is the outer experiment surround (d1). Inside it, a visible H4 is the lesson page title (d2 / lesson H1), articles use H5 (d3 / lesson H2), blocks H6 (d4 / lesson H3), and component titles accessible heading level 7 (d5 / lesson H4). A menu is navigation, not an additional heading depth. Aims and the first block start open; complete an activity to fade in and open the next block. Every revealed block remains collapsible. Progress is local to this page and resets on reload.</p>
