AB System Cheat-Sheet

Tune and build themes in the studio, or browse the component reference. One hue drives the scales, surfaces, accents and semantics.

Reference order: core tokens and scales, color relationships, semantic and heading systems, then reusable components.

1 · HSL Tuner

hsl(202 72% 14%)

2.0 Tokens — the one knob

Change --brand-h and the whole system re-themes. Saturations: --brand-s (colourful) and --grey-s (blue-grey neutrals).

:root { --brand-h: 202; --brand-s: 72%; --grey-s: 12%; }

2.1 Scales

Brand --blue-50…950 · Blue-grey --grey-50…950 · Pure grey --gray-50…950

3 · Semantic colours — one formula
