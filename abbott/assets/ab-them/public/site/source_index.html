3.0 Color theory

Colour harmony data-harmony · .hue-*

Rethemed containers — hover or keyboard-focus a button to illuminate its whole card with that harmony colour. Reduced-motion preferences disable the transition.

Base subtree — a link & accents.

Extra hue formulas: Tight analogous uses +15°, −15°, +30°; Wide analogous +60°, −60°, +120°; Wide split +135°, +225°, +180°; Rectangle +45°, +180°, +225°. Pentadic steps by 72° over five anchors; Hexadic by 60° over six. Extra colours cycle those anchors with lightness variations. Spectrum evenly divides the full circle by the selected count. Golden angle advances by 180 × (3 − √5) degrees per colour, wrapping at 360°. All formulas rotate with the foundation and work with 3–10 colours.

The brand hue stays the single source of truth. A preset adds angle offsets and the siblings fall out by calc(), so they rotate as you drag the hue. The demo cards use the .hue-2/3/4 scheme — a whole subtree rethemed onto a spawned hue (links, buttons, borders all follow), which is the "full remap" ready in theme.css.

Click a harmony swatch to use its exact hue, saturation and brightness as the main accent, just like a semantic button. The selected colour is saved and exported unchanged in both modes. Use this section's main-system button to apply the whole harmony palette by role again. Changing the preset or colour count also returns to whole-palette mode.

Separate compact colour buttons each use a different symmetrical Google Material Symbol. Hover or focus to invert the fill into a coloured outline and glyph; click to make that colour the main accent.

3.0 Theme imports and studio output mapping




  
Current kit: two standalone starter files, not an explicit import manifest. Its README recommends zzz-fluid-baseline.less as the only owner of type/layout and zzz-overrides.less for colour, surfaces, depth and dark mode. Both files currently contain typography/layout rules, so importing both unchanged creates competing ownership. Confirm the installed Adapt/Vanilla version and actual Grunt import order before integrating; a zzz filename is an ordering convention, not proof of precedence.

LESS @import (less) inlines CSS into the build; a plain CSS import can remain a browser request. Generated CSS must stay valid LESS input. Register one entry point in the installed build and keep partials outside any auto-import glob to avoid duplicate output. If a LESS variable is bridged to var(--token), use it only in CSS declarations: LESS colour functions and compile-time arithmetic cannot evaluate runtime custom properties.

  
:root { --adapt-block-gap: var(--ab-space-item-margin); }
@block-gap: ~"var(--adapt-block-gap)";
.component__container { gap: @block-gap; }

  
Current studio exports remain a complete single CSS bundle plus scheme JSON. CLI/API output composes the base template, ingredient overrides, connectors, colour, typography, spacing, layout, cards and custom CSS; external connector imports go first. Browser export uses the same domain generators. An Adapt-specific split export would extract domain outputs instead of importing that full bundle, then add adapters for BEM selectors and LESS-only defaults. Do not wrap existing unlayered overrides in CSS layers without deciding precedence against Vanilla.

2.0 The master clock and reusable code





Copy any example for a self-contained SVG, wrapper and animation stylesheet. No animation library is needed. Place these variables on a common ancestor to control every drawing together:


:root {
  --edu-duration: 4s;    /* total time for one sequence */
  --edu-speed: 1;        /* master multiplier: 2 = twice as fast */
  --edu-local-speed: 1;  /* override on one drawing if needed */
  --edu-iterations: 1;   /* use infinite to repeat */
}
/* Example local override: */
.my-fast-drawing { --edu-local-speed: 2; }


Add edu-running to the SVG wrapper to draw it. Add edu-paused to pause, or edu-no-arrows to hide arrow strokes. Remove and re-add edu-running with a layout flush to replay. Separate examples share the same keyframe names, so include the common stylesheet only once when combining them. With arrows hidden, their time slots remain as short pauses; the master cycle stays the same length.


Line and box paths can be swapped independently. Every path uses pathLength="1"; normalized dash offsets draw straight and curved strokes with the same timing system. Segment count changes how the single complete outline is divided, not how many circles or triangles appear. Colour converts to the host theme's --accent, with a teal fallback outside the workbench.


The board is a theme-tinted teaching surface, not a fixed black colour. SVG strokes stay sharp at any size. A light chalk-like shadow and rounded caps suggest a hand-drawn stroke without flashing, random jitter or heavy noise filters.


Research: MDN: pathLength, stroke-dashoffset, animation-duration, and prefers-reduced-motion. Reduced motion always shows the completed shape; playback is opt-in.
