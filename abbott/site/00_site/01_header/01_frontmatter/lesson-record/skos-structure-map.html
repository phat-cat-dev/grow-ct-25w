SKOS structure map — a concept scheme, read as a page frame

The same nesting technique as the Adapt DOM map, pointed at meaning instead of markup. A SKOS concept scheme is already a tree: one scheme holds a few top concepts, each gathers narrower concepts, and each concept carries a definition made of ordered steps, plus sideways related links. Read that tree top-to-bottom and it tells you how to lay out a page: the hierarchy is the frame; the scopeNote and steps are the content that goes inside it.

From SKOS graph to page frame

What SKOS gives you (fixed meaning)

  • one ConceptScheme — the vocabulary’s identity
  • hasTopConcept / broader / narrower — the containment tree
  • prefLabel (one) + altLabel (synonyms)
  • scopeNote — the meaning, in a sentence
  • definition → ProcessSteps — an ordered how-to
  • related — non-hierarchical, symmetric cross-links

The page it structures

  • the course / site — and its top-level menu
  • menu order & nesting — the tree is the navigation
  • prefLabel → the heading; altLabel → search terms, aria-label
  • scopeNote → the lede / intro paragraph under the heading
  • one step → one ordered component (a numbered block each)
  • related → a “see also” strip — links, never nesting

Two rules the SKOS shape enforces on the page

Hierarchy is the frame

  • broader/narrower is a tree — it decides nesting and menu order
  • a concept sits under exactly the family it declares; no concept floats free of the scheme
  • ProcessSteps are ordered — render them in sequence, numbered

Related is a link, not a limb

  • related is symmetric and non-transitive — never promote it to nesting
  • it may point outside this scheme (CRAAP/RADAR/ROBOT) — render as an external link, not a page
  • use it for “see also” / recommended-next, so the tree stays a clean hierarchy

Companion to adapt-dom-map.html (same nesting technique, warmer palette) and academic-processes.skos.jsonld (the source vocabulary). The DOM map shows how the markup nests; this shows how the meaning nests — and both trees, read top-down, tell you how to lay out the page.
