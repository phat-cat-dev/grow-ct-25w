SKOS accordion template — hierarchy as animated reveals

The same warm palette as the static map, now driven by data. Edit the DATA block at the top of the script and this page rebuilds itself as a nested set of accordions: click any row to reveal its meaning, its ordered steps (which fade in one by one), and its sideways links. Prefilled with the SKOS academic-processes scheme — swap DATA for any tree of the shape shown below and the hierarchy redraws to fit.

How to feed it. One source of truth: the DATA object (top of the <script>). A node is { id, label, kind, note?, alt?, steps?, related?, children? } — kind picks the colour (scheme/family/concept… from the legend), steps is [{title,text}], related is [{label, to?, external?}] (to = another node’s id, so the chip jumps to it). A fromSkos(graph) helper is included: assign const DATA = fromSkos(yourSkosJsonLd) to drive it straight from a SKOS @graph instead.

What the accordion is teaching

Hierarchy is the frame

  • nesting = broader/narrower — the accordion depth is the tree
  • steps open in order, numbered — a definition is a sequence, not a set
  • a scopeNote is the lede that greets you when a concept opens

Related is a link, not a limb

  • a related chip jumps to its target — it never nests it
  • dashed chips point outside the scheme (CRAAP/RADAR…) — no jump
  • that keeps the tree a clean hierarchy while cross-links stay navigable

Interactive companion to skos-structure-map.html (static, same palette) and adapt-dom-map.html (the markup version). Source vocabulary: academic-processes.skos.jsonld.
