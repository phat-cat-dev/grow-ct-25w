Context packs

Each pack writes a statement, then marks it up step by step — a fade hands you the change, a mark draws itself on like a tutor’s hand, and the steps hold the order the process depends on. Click to advance. Launch one as a modal, drop it in an accordion, or embed it inline.

New: the 20 Academic Process activities (a process stage type), plus source-evaluation three ways — CRAAP, RADAR and ROBOT. Model and docs in .dev/docs/academic-processes.md.

A pack is data — see packs/*.json and the schema in context-pack-schema.json. Stage types: annotated-prose (inline-commentary), checklist (spot-the-error), assembly (sequential-process). Marks reuse the animation-manager draw-on engine and its semantic colour roles. To author new packs, see prompts/author-context-pack.md.
Served over http:// the packs load by fetch; opening the file directly needs a local server (python -m http.server).
