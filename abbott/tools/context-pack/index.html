<context-pack>

A self-registering custom element around the context-pack renderer. Give it a pack via src, an inline JSON <script>, or the .pack property, and pick how it launches. It emits context-pack:ready, :step and :complete, and adds the is-complete class — the hooks an Adapt component will use to set completion.

Inline — from a src URL

<context-pack src="…/marking-feedback.json"></context-pack>

loading…

Modal — click to launch full-width

<context-pack launch="modal" src="…/craap.json"></context-pack>

Accordion

<context-pack launch="accordion" src="…/referencing.json"></context-pack>

Inline JSON — no fetch, works offline

A pack can live inside the element as a <script type="application/json">.

Served over http:// from the repo root so the src packs resolve (python -m http.server). The engine mirrors tools/context-packs (the authoring sandbox); this is the embeddable component. Next step: an Adapt component that sets .pack in postRender and marks completion on context-pack:complete.
