Mark up the page by hand.

Open the Gallery in the top bar to browse every note-taking mark extracted from the marks gallery. Pick one, set its speed, size, rotation and semantic colour under Adjust, then Insert it into this page.

A landscape is built from a foreground, a middle ground, and a backdrop. Depth is a choice, not an accident. Select the word backdrop above and try the strike-through, or mark every horizon with the keyword tool.

Tip: the colour role follows the page theme — switch this page to dark (via your OS) and the marks re-tint automatically.

Settings are saved locally for this page. Export JSON for your settings, or export a self-contained HTML snippet (filter + stylesheet + mark) for any other page.
