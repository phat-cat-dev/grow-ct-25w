# gowTimeline

## Purpose
Displays a chronological sequence of 2-12 events, ascending or descending, as a vertical track with dots.

## Config
`title`, `items[]` (each: time, label, body); ordering ascending or descending.

## When to use
Showing how something unfolds over time, or an ordered set of stages. Its `_component` is `gowTimeline` so it coexists with adapt-abbott-timeline (`_component: timeline`).
