# callout

## Purpose
Displays a short, categorised message box (info, warning, tip, example, note or definition) that sits beside the main prose.

## Config
`_type` (info|warning|tip|example|note|definition), `title`, `body`.

## When to use
A brief aside that emphasises or flags one point - a tip, a warning, a worked micro-example. Not for running teaching prose (use palette/text) and not a full content block.
