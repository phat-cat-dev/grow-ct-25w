# textTagging

## Purpose
An interactive text-tagging / annotation activity: learners tag spans of a passage with categories drawn from a palette. Ported from pw02's text-tagging activity and congen11's text-tagging schema.

## Config
`title`, `body` (the passage), `instruction`; a palette of tag categories.

## When to use
A learn-by-doing classification activity over a real passage - learners identify and label the parts (claim / evidence / assumption, say). Serves the classification content shape at an activity slot; authored in activity mode, not as a graded check.
