# GROW-BUILD — the Adapt Framework build

**What it is:** a fork of Adapt Framework 5.56.2 (`package.json` name
`adapt_framework`) with a custom theme + a large component/extension library. It
compiles one course into a browser-playable and SCORM-packageable build. This is
where build / preview / SCORM happen.

## Key locations
- `Gruntfile.js`, `grunt/` — the Adapt build system (standard loader; per-task config in `grunt/config/`, tasks in `grunt/tasks/`, helpers in `grunt/helpers/`).
- `src/core/` — Adapt core.
- `src/theme/` — themes. **Active today: `adapt-contrib-vanilla`** + the Abbott styling **extension** `adapt-ab-theme` (see Theming).
- `src/components/` — 32 content components (stock `adapt-contrib-*` + custom `adapt-ab-*` / `adapt-abbott-*`).
- `src/extensions/` — 23 extensions (contrib + custom).
- `src/menu/adapt-contrib-boxMenu` — the menu plugin.
- `src/course` — **symlink** to the active course under `courses/`. This is the build input.
- `adapt.json` — contrib plugin manifest (`adapt install` reads it). `.bowerrc` → installs to `src/plugins`.
- `build/` — compiled output. `exports/` — generated CSS / theme / reference artefacts.
- `courses/<slug>/` — authored courses (shared with GROW-CONTEXT). `content/context-packs/` — context prose packs.

## The course switch
`src/course` is a symlink; `grunt build` copies `src/course/ → build/course/`, so
whatever it points at is what builds. Repoint it with `_workspace/grunt-menu/viewer.js`
(`ck` link · `cg` generate-with-context · `cr` rebuild) or `ln -sfn ../courses/<slug> src/course`.
`tools/check-build-target.js` refuses a build if the symlink resolves outside `courses/`.

## How to
- **Install:** `npm ci`, then **`npm run adapt-install`** (= `adapt install && node scripts/apply-vendor-patches.js`).
  ⚠️ **Never run raw `adapt install`** — it wipes the vendor fixes in `patches/`. (This is the likely reason features broke when the grow-ct container ran plain `npx adapt install`.)
- **Build:** `npx grunt build` (viewer `bb`). **Preview:** `npx grunt server` (viewer `bs`). **Dev watch:** `npx grunt dev`.
- **SCORM:** `node package-scorm.js --context=<subject> --tier=<slug>` → merges context, swaps the symlink, builds, zips `build/` (with `imsmanifest.xml` at the top) → `scorm-packages/`, restores the symlink.

## Theming (current + pending)
Vanilla stays the base; `adapt-ab-theme` (extension `abTheme`, no `targetAttribute`)
layers the Abbott look via a `--ab-*` token system generated by `tools/adapt-ab/*`
from `cm-global.css`, driven by `_htmlClasses` in the course config
(`ab-theme ab-profile-ember cm-theme-dark-blue-grey ab-force-light`).

**Pending decision:** adopt the newer `_grow` *full theme* from the `grow-ct` repo
instead (it replaces vanilla outright). See [GROW-CT-IMPORT.md](GROW-CT-IMPORT.md).
