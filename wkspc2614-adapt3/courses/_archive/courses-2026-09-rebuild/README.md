## presenting-introductory

Retired 19 September 2026 (ruled by Abbott). The Phase 6 rebuild
restarts on a pathway with no archived predecessor, so this course's
Phase A design work — closed 18 September 2026, nine gates, no
B-gates — stands as a record but is not built, renumbered, or
regenerated. Its lesson keys (`L02` upward, no `L01`) predate the
`L01`-start numbering convention (decision `LN-1`) and are exactly
the kind of prototype-legacy numbering that convention exists to
replace going forward.

This directory is distinct from `archive/courses-2026-09/`, which
holds the four courses audited in the Manual Course Audit 2026-09
(a separate, earlier archiving on 16 September 2026, unrelated to
this rebuild retirement).
