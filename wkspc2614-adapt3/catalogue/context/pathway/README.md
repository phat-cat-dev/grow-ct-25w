# catalogue/context/pathway/

Rich per-pathway capability reference, one file per pathway (13 files,
e.g. `academic-writing.json`). This is the aggregated authoring reference
for each pathway, **regenerated by `tools/build-pathway-reference.py`**
(not a plain hand-edited store — see that script's docstring for the full
list of source stores it merges: card plan, core A10 competency doc, card
vocabulary, book grounding, etc.).

## Shape

- `identity` — what the pathway is: front matter, card-plan number/practice
  noun, catalogue placement (embeds a copy of this pathway's
  `../pathways.json` index entry, including its `routes` and `file`
  pointer)
- `capabilities[]` — 9 entries (3 tiers x 3), each with:
  - `capabilityId`, `tier`, `fheqLevel`, `statement`, `knowledgeKind`
  - `qf[]` — FHEQ/QF extract references (not universal-benchmark references)
  - `competency` — academic statement, verbs, theory doc ids, professional
    equivalence
  - `vocabulary` — verbs/terms/keywords/bookTopics/benchmarkHits
  - `bookGrounding` — source-book chapter references
- `tierProgression`, `theorySpine`, `crossCutting`, `gaps`, `provenance`

## Regenerating

```
python3 tools/build-pathway-reference.py --pathway <id>
python3 tools/build-pathway-reference.py --all [--dry-run]
```

## Consumers

Read by `tools/build-pathway-tier-readings.py` and
`tools/build-pathway-views.py` as one of the four joined stores behind a
pathway's benchmark chain. Kept deliberately apart from
`../pathway-evidence/`, which is hand-authored and never regenerated by
this script.
