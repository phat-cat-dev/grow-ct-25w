# Excelling at University - reference links

This file controls where the "See page X of Chapter N..." reference links in
every course send the student. It is read by a non-technical editor and
turned into the real config by a build step - you do not need to touch
anything except the one line below.

## Current link set

Use: Primary

Type exactly `Primary` or `Fallback` on the "Use:" line above, then save this
file and ask the course team to rebuild the redirect config (one command:
`node tools/build-redirect-config.js`).

- **Primary** sends students to the EBSCO database copy of the book (the one
  the university library subscribes to). Use this normally.
- **Fallback** sends students to the Cardiff Met MetSearch library-catalogue
  page instead. Switch to this only if the EBSCO database link stops working
  (e.g. the subscription changes or EBSCO restructures their links) and you
  need every course's links fixed at once without waiting for anyone to edit
  course content.
